Povy Checkout API

Integra pagos y reembolsos de Povy para copiar y pegar sin perder tiempo.

Esto es lo mínimo para conectar Povy en cualquier sitio: una función para cobrar, una para reembolsar y ejemplos listos en varios lenguajes.

Lo que necesitas

Esto es lo que pegas en tu proyecto para que apunte a Povy y lo puedas usar con normalidad.

const PovyApi = {
  baseUrl: 'https://backend-povy.onrender.com',

  buildUrl(path) {
    return `${this.baseUrl}${path}`;
  },

  async request(path, options = {}) {
    const response = await fetch(this.buildUrl(path), {
      ...options,
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        ...(options.headers || {})
      }
    });

    if (!response.ok) {
      const error = await response.json().catch(() => ({}));
      throw new Error(error.message || 'Error usando Povy.');
    }

    return response.json();
  }
};

Con esto ya tienes una base reutilizable para que tu sistema apunte a Povy. Luego solo cambias el endpoint que usarás para pago o reembolso.

}

Reembolso

Esto es lo que usas para que funcione el reembolso con Povy.

async function reembolsarConPovy(transactionId, token) {
  const data = await PovyApi.request(`/api/payments/${transactionId}/refund`, {
    headers: {
      Authorization: `Bearer ${token}`
    },
    body: JSON.stringify({
      amount: 10.00
    })
  });

  console.log(data);
}

Necesitas un Bearer token de una sesión Povy, el transactionId del pago aprobado y el monto parcial o total que quieras devolver.
