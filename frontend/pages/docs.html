Povy API (sandbox)

Base URL: https://backend-povy.onrender.com

La mejora principal es que ya no tienes que copiar tarjeta por tarjeta desde la UI. Ahora haces login, guardas el token y puedes pedir directamente todas tus cuentas con sus tarjetas asociadas.

1. Login y token

POST /api/auth/login
{
  "email": "tu-correo@ejemplo.com",
  "password": "tu-password"
}

// respuesta
{
  "token": "TOKEN_AQUI",
  "user": {
    "id": "...",
    "name": "Tu nombre",
    "email": "tu-correo@ejemplo.com"
  }
}

2. Obtener todas tus cuentas y tarjetas

Este endpoint ya devuelve solo tus cuentas y dentro de cada cuenta viene la tarjeta. Eso te permite usar cualquiera de tus tarjetas en tu app sin andar copiando datos a mano.

GET /api/accounts
Authorization: Bearer TOKEN_AQUI

// respuesta resumida
[
  {
    "accountNumber": "001-00000001",
    "ownerName": "Tu nombre",
    "balance": 10000,
    "currency": "EUR",
    "card": {
      "cardNumber": "4111111111111111",
      "expMonth": "12",
      "expYear": "29",
      "cvv": "123"
    }
  }
]

3. Flujo recomendado en JavaScript

const BASE_URL = 'https://backend-povy.onrender.com';

async function loginPovy(email, password) {
  const resp = await fetch(`${BASE_URL}/api/auth/login`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password })
  });

  return resp.json();
}

async function getAccounts(token) {
  const resp = await fetch(`${BASE_URL}/api/accounts`, {
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${token}`
    }
  });

  return resp.json();
}

async function payWithOneOfMyCards(email, password, amount) {
  const auth = await loginPovy(email, password);
  const accounts = await getAccounts(auth.token);

  const selected = accounts[0];
  const card = selected.card;

  const resp = await fetch(`${BASE_URL}/api/payments/card`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${auth.token}`
    },
    body: JSON.stringify({
      cardNumber: card.cardNumber,
      expMonth: card.expMonth,
      expYear: card.expYear,
      cvv: card.cvv,
      amount,
      currency: selected.currency,
      description: 'Compra sandbox',
      merchantName: 'Mi tienda demo'
    })
  });

  return resp.json();
}

4. Devoluciones

POST /api/payments/:transactionId/refund
Authorization: Bearer TOKEN_AQUI
{
  "amount": 49.99
}

// Solo funciona para pagos aprobados.
// Si omites amount, devuelve el total del pago original.

5. Ajustes utiles

  • PATCH /api/accounts/:accountNumber con { "addBalance": 100 } para sumar o restar.
  • PATCH /api/accounts/:accountNumber con { "balance": 500 } para fijar saldo exacto.
  • Monedas soportadas: USD, MXN, JPY y EUR.
