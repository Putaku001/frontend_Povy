Povy Checkout API

Integra pagos y reembolsos de Povy para copiar y pegar sin perder tiempo.

Esto es lo mínimo para conectar Povy en cualquier sitio: una función para cobrar, una para reembolsar y ejemplos listos en varios lenguajes.

Base URL

https://backend-povy.onrender.com

Pago

POST /api/payments

Refund

POST /api/payments/:transactionId/refund

Lo que necesitas

Pon esto en tu código y ya tienes la base para cobrar con Povy.

const PovyApi = {
  baseUrl: 'https://backend-povy.onrender.com',

  async pay({ amount, currency = 'USD', description, merchantName }) {
    const response = await fetch(`${this.baseUrl}/api/payments`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        amount,
        currency,
        description,
        merchantName
      })
    });

    if (!response.ok) {
      const error = await response.json().catch(() => ({}));
      throw new Error(error.message || 'No se pudo procesar el pago con Povy.');
    }

    return response.json();
  },

  async refund(transactionId, { amount } = {}, token) {
    const response = await fetch(`${this.baseUrl}/api/payments/${transactionId}/refund`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${token}`
      },
      body: JSON.stringify(amount ? { amount } : {})
    });

    if (!response.ok) {
      const error = await response.json().catch(() => ({}));
      throw new Error(error.message || 'No se pudo hacer el reembolso.');
    }

    return response.json();
  }
};

Para cobrar

Solo necesitas amount, currency, description y merchantName.

Para reembolsar

Necesitas transactionId y un Bearer token de una sesión Povy.

Respuesta

Te devuelve transactionId, estado, monto y mensaje para guardarlo en tu sistema.

Reembolsos en tu sistema

Guarda el transactionId del cobro. Luego lo usas para devolver total o parcial.

const PovyApi = {
  baseUrl: 'https://backend-povy.onrender.com'
};

async function reembolsarConPovy(transactionId, token) {
  const response = await fetch(`${PovyApi.baseUrl}/api/payments/${transactionId}/refund`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${token}`
    },
    body: JSON.stringify({
      amount: 10.00
    })
  });

  const data = await response.json();
  console.log(data);
}

1. Login

Obtén un token iniciando sesión en Povy.

2. TransactionId

Guarda el transactionId aprobado del pago original.

3. Refund

Llama al endpoint con monto parcial o vacío para devolver el total.
